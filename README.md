Python Lab 1 - Conditional Statements
Bu repozitoriyada Python fənni üzrə birinci laboratoriya işinin kodları yerləşir. Tapşırıqlar şərt operatorlarına ('if', 'elif', 'else') və məntiqi əməliyyatlara aiddir.

1. Task 1: BMI Calculator
İstifadəçidən çəki (kq) və boy (metr) dəyərlərini soruşur.
Düstur əsasən Bədən Kütlə İndeksini (BMI) hesablayır və hansı kateqoriyaya aid olduğunu ekrana çıxarır!

2. Task 2: Chinese Zodiac Calculator
İstifadəçinin daxil etdiyi doğum ilinə əsasən Çin Təqvimində hansı heyvan ilinə (bürclə) düşdüyünü tapır.

3. Task 3: Birthday Guessing Game
Təqdim olunan 5 fərqli rəqəm qrupu vasitəsilə istifadəçinin doğum gününü tapmaq üçün yazılmış oyundur.

Proqramı necə işə salmalı?
Kodları yoxlamaq üçün istənilən Python redaktorunda müvafiq faylı açıb "Run" etmək kifayətdir.
